# 뻥! 승부차기 ⚽

카메라로 가족을 인식해서 **손으로 방향을 고르고, 발로 뻥! 차서** 골을 넣는 가족용 승부차기 웹 게임.
[와르르 캐치](https://github.com/yagungom/wareureu)와 같은 방식으로 만들었습니다. 설치 없이 **크롬(웹/모바일 웹)** 에서 돌아가고, 폰을 **TV에 미러링**해서 하는 게 기본이에요.

- 빌드 도구 없음: 정적 파일 그대로 배포 (HTML + JS 모듈)
- 사람 인식: MediaPipe (기기 안에서 처리, 영상 전송 없음). 엔진·모델을 이 폴더에 같이 넣어 외부 서버를 부르지 않음
  - 자세 인식으로 **손**(조준)과 **발**(슛) 위치를 찾음
  - 인식은 별도 처리(Web Worker)에서 돌려 게임 화면은 부드럽게
- 한 판 = 슛 10번. 키퍼는 아무 데로나 뛰고, 같은 쪽으로 뛰어도 높은 공은 잘 못 막음
- 플레이 방식 2종: 📺 카메라 모드(손으로 조준·발로 슛) / 📱 폰 모드(풍선 톡 → 공을 위로 휙)
- 난이도 2종: 일반 / 🍼 아기 모드(살짝만 차도 슛, 키퍼가 반대쪽으로 더 자주, 크로스바 넘김 없음)
- 기록: 이 기기에 저장 (오늘/이번 주/이번 달, 카메라·폰 × 일반·아기 모드 따로)

## 1. 배포 (Vercel, 약 5분)

카메라는 **https 주소에서만** 켜지므로 배포가 필요합니다.

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [vercel.com](https://vercel.com) → **Add New → Project** → 저장소 선택 → Framework: **Other** → Deploy (빌드 설정 필요 없음)
3. 받은 `https://xxx.vercel.app` 주소를 갤럭시 크롬으로 열고, 크롬 메뉴 → **홈 화면에 추가** 하면 전체화면 앱처럼 실행됩니다.

**PC에서 먼저 확인:** 폴더에서 `npx serve .` → `http://localhost:3000`. 카메라 없이 보려면 주소 뒤에 `?touch=1`.

## 2. 하는 법

| 단계 | 카메라 모드 | 폰 모드 |
|---|---|---|
| 시작 | 노란 풍선에 손을 1초 | 풍선을 누르거나 "▶ 바로 시작" |
| ① 방향 | 골대 아래 **왼쪽·가운데·오른쪽** 풍선에 손을 0.5초 (거울처럼 내 왼손 쪽 = 화면 왼쪽) | 풍선을 톡 |
| ② 슛 | 공 앞에서 한 발을 앞으로 **휙** 차기. 빠를수록 높이 | 공을 손가락으로 **위로 휙** 밀기. 빠를수록 높이 (그냥 톡 = 땅볼) |
| ③ 결과 | 골 / 선방 / 하늘로 슝(너무 셈) | 같음 |

PC 키보드: ← ↑ → 로 방향, 1·2·3 = 약·중·강, 4 = 너무 세게.

**폰 놓는 법:** 폰을 가로로 **낮게** 세워 두고(의자·낮은 선반), **발까지 화면에 보이게** 3걸음쯤 뒤에 서세요. 발이 안 보이면 화면에 안내가 나와요.

## 3. 규칙

| 항목 | 내용 |
|---|---|
| 한 판 | 슛 10번 |
| 높이 | 발차기 속도로 정함: 약하게 = 땅볼, 보통 = 중간, 세게 = 위쪽 |
| 키퍼 | 일반: 1/3 확률로 같은 방향 / 아기 모드: 15%. 같은 방향일 때 막을 확률 — 일반: 땅볼 95%·중간 70%·높게 30%, 아기: 60%·40%·10% |
| 너무 셈 | 일반 모드에서 아주 세게 차면 크로스바 위로 (세기 조절이 실력) |
| 점수 | 골 100점 · 위쪽 구석(왼쪽·오른쪽 + 높게) +50점 · 연속 골은 2연속부터 (연속 수 − 1) × 20점 추가 |
| 배려 | 화면에 사람이 4초간 없으면 자동 일시정지. 슛 차례에 시간 제한 없음 |

숫자는 모두 `js/config.js` 에서 바꿀 수 있어요.

## 4. 발차기 세기 맞추기 (처음 한 번 해 보세요)

발차기 세기는 **다리 길이 기준 속도**(다리 길이/초)로 잽니다. 멀리 서든 가까이 서든 같은 기준이에요.
아이마다, 폰마다 다를 수 있어서 처음엔 조절이 필요할 수 있어요.

1. ⚙️ 설정 → **성능 정보 표시** 켜기 → 화면 위에 `발 속도`, `마지막 슛 속도→세기%` 가 나와요.
2. 아이가 살살 찰 때와 세게 찰 때 숫자를 봐 두고, `js/config.js` 의 `KICK` 을 고칩니다.
   - `trigger`: 이보다 느리면 슛으로 안 봄 → 살살 찼는데 안 나가면 낮추기
   - `low` / `high`: 이 사이가 땅볼~위쪽 → 세게 차도 땅볼이면 `high` 를 낮추기
   - `over`: 이보다 빠르면 크로스바 위로 (일반 모드만)
3. 사람이 골대를 너무 가리거나 손이 풍선에 안 닿으면 `PERSON_SCALE` (기본 0.74)을 조절하세요.

## 5. 파일 구조

```
index.html              화면 구성
css/style.css           디자인 (와르르 캐치와 같은 스타일)
js/config.js            ★ 설정 (발차기 기준, 키퍼 확률, 점수 규칙)
js/main.js              화면 흐름
js/game.js              게임 엔진 (경기장·키퍼 그리기, 조준→슛→결과, 점수·HUD)
js/kick.js              발차기 판정 (발 속도·높이 → 세기)
js/vision.js            카메라 + 화면 합성 + 손 판정 + 폰(터치) 모드
js/vision-core.js       인식 핵심 (자세 인식·사람 분리) — 손·발 위치 출력
js/vision-worker.js     별도 처리(Web Worker)
js/audio.js             효과음 (직접 합성, 음원 파일 없음)
js/ranking.js chart.js  기기 기록, 기록 그래프·표
js/fullscreen.js        전체화면 (OS·브라우저별 처리)
js/nickname.js          팀 이름 규칙 (욕설·전화번호 막기)
vendor/, models/        사람 인식 엔진·모델 (수정 불필요)
vercel.json, _headers   보안 헤더
```

## 6. 보안·개인정보

카메라 영상은 폰 메모리 안에서만 처리하고 저장·전송하지 않습니다. 서버 통신이 없고(CSP로 외부 연결 차단), 기록은 이 기기에만 저장돼요.
팀 이름은 실명 대신 별명, 숫자 7자리 이상 금지, 욕설 필터 (와르르 캐치와 같은 규칙).
